# Code of conduct

We want this to be a friendly, helpful place for everyone – beginners and security professionals alike.

- Be respectful. No harassment, insults or discrimination.
- Help, don't shame. Many people asking questions are not technical.
- Defensive use only. Do not post working malware, exploits against third parties or stolen data.
- Keep secrets out. Never post API keys, passwords or private data – yours or anyone else's.

Maintainers may edit, hide or remove content and block accounts that break these rules.
This code is adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
