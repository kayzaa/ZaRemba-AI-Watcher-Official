# Security policy

ZaRemba AI Watcher is a security product, so we take vulnerabilities in it very seriously.

## Reporting a vulnerability in ZaRemba
**Please do not open a public issue.** Use GitHub's private reporting instead:

1. Go to the **[Security tab](https://github.com/kayzaa/ZaRemba-AI-Watcher-Official/security)** of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, affected version and steps to reproduce.

We aim to acknowledge reports within **3 business days** and to ship a fix for confirmed critical issues as fast as possible.
We are happy to credit you in the release notes if you wish.

## Reporting a malicious AI extension, skill or package
That is not a vulnerability in ZaRemba – please use the public
[threat report form](https://github.com/kayzaa/ZaRemba-AI-Watcher-Official/issues/new?template=threat_report.yml)
so the whole community benefits. **Never attach live malware**; names, versions, links and hashes are enough.

## Supported versions
| Version | Supported |
|---|---|
| 0.2.x (latest) | ✅ |
| 0.1.x | ⚠️ please update |
| older | ❌ – please update |
