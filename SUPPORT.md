# Getting help

1. **Read the docs** – [Installation guide](docs/INSTALL.md) · [Detection rules](docs/DETECTIONS.md) · [FAQ](README.md#-faq)
2. **Search existing issues** – someone may already have asked.
3. **Open an issue** with the right form:
   - 🐞 [Bug report](https://github.com/kayzaa/ZaRemba-AI-Watcher-Official/issues/new?template=bug_report.yml)
   - 🎯 [False positive](https://github.com/kayzaa/ZaRemba-AI-Watcher-Official/issues/new?template=false_positive.yml)
   - ☠️ [Threat report](https://github.com/kayzaa/ZaRemba-AI-Watcher-Official/issues/new?template=threat_report.yml)
   - 💡 [Feature request](https://github.com/kayzaa/ZaRemba-AI-Watcher-Official/issues/new?template=feature_request.yml)

Before posting scan output, check that it contains no personal paths or data you don't want to share.
ZaRemba never prints full keys, but file paths may contain your user name.
