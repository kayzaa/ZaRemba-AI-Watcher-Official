## 🛡️ ZaRemba AI Watcher 1.2 – Deep defense

AI attacks rarely look like classic malware. They hide instructions in web pages, poison the rules files your agents
follow, ship worms inside editor extensions and booby-trap model files. Version 1.2 goes after all of them – and
**measures** the result instead of claiming it.

### 🧪 Attack Lab: 26 of 26
`zaremba lab` runs harmless simulations of every class of AI attack we know of, mapped to the OWASP Top 10 for Agentic
Applications, through the real detection engines. ZaRemba 1.2 detects all 26. It is our own lab, not an independent
test – [details and limits](https://github.com/kayzaa/ZaRemba-AI-Watcher-Official/blob/main/docs/ATTACK_LAB.md).

### ✨ New
- 🧠 **Injection Shield for agents** – every result your AI agent receives (web pages, files, MCP answers) is checked for
  hidden instructions. Claude Code (verified in a real session) and Gemini CLI. Already-protected agents are upgraded
  automatically.
- 🕵️ **Agent forensics** – looks back through your agent sessions: hidden instructions it read, dangerous actions it
  took, API keys left in its chat history.
- 📜 **Poisoned rules files** – hidden orders in `CLAUDE.md`, `AGENTS.md`, `GEMINI.md`, `.cursorrules` and friends.
- 🧩 **IDE extension scan** – VS Code, Cursor, Windsurf and VSCodium extensions with invisible code (the GlassWorm
  technique) or named in GlassWorm reports.
- 🧬 **Model file scan** – AI models that would run commands when loaded (pickle), and models packed to evade scanners
  (nullifAI).
- 🦠 **AI-steered malware** – scripts that ask an AI model for commands and run them (LameHug / PROMPTFLUX pattern), and
  scripts that start AI agents with their safety prompts switched off (s1ngularity).
- 🤫 Fewer false alarms: example keys from docs are ignored; text written to files is not treated as a command.

Rule list: [Detection rules](https://github.com/kayzaa/ZaRemba-AI-Watcher-Official/blob/main/docs/DETECTIONS.md)
