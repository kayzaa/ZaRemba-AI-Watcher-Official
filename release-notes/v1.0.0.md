## 🛡️ ZaRemba AI Watcher 1.0 – the desktop app

The AI-only security guard is now an app. Install it, click **Protect everything**, and every AI agent, MCP server and
decoy on your computer is under watch – with a live protection score, instant alerts and automatic updates.

### ✨ New in 1.0
- 🖥️ **Desktop app** for Windows, macOS and Linux – overview, AI Agents, MCP Firewall, AI Tripwire, Network Watch, Scan, Activity
- ⚡ **Protect everything** in one click: Agent Guard for every installed agent, MCP Firewall, AI Tripwire, background watch
- 🔔 **Live alerts** from the tray: decoy touched, agent action blocked, poisoned MCP tool quarantined, unknown program talking to AI
- 🔄 **Signed automatic updates** – updates are verified against ZaRemba's release key; forged updates are rejected
- 🧠 **Daily threat intelligence** – a research team adds newly disclosed malicious MCP servers, skills and packages every day; the signed feed reaches your app automatically
- ⌨️ Command line included and updated (`zaremba update` for the latest threat intelligence)

- Verify downloads with `SHA256SUMS.txt`.
