## 🛑 ZaRemba AI Watcher 0.4.0 – Agent Guard & MCP Firewall

Your AI agents can now be stopped **before** they do something dangerous.

### ✨ Agent Guard – real-time protection for your AI agents
`zaremba guard install` connects ZaRemba to your agents through their **official hook systems**. Every action is
checked before it runs:

| Agent | Status |
|---|---|
| Claude Code | ✅ verified in a real session |
| Gemini CLI · Cursor · Windsurf · GitHub Copilot CLI | 🧪 experimental |

- ⛔ **Blocks** access to SSH keys, cloud logins, tokens, keychains, browser passwords & cookies and crypto wallets,
  touching tripwire decoys, download-and-run commands, agents launched without safety prompts (the s1ngularity trick),
  disk wipes and attempts to switch ZaRemba off
- ❓ **Asks** before reading `.env` files, uploading files, adding autostart entries or contacting paste/webhook services
- Your agent settings are restored exactly on `zaremba guard uninstall`

Guide: [Agent Guard](https://github.com/kayzaa/ZaRemba-AI-Watcher-Official/blob/main/docs/AGENT_GUARD.md)

### 🔥 MCP Firewall – for every MCP app
`zaremba mcp protect` puts a firewall between your AI apps (Claude Desktop, Claude Code, Cursor, Windsurf, VS Code,
Gemini CLI …) and each local MCP server:
- Dangerous tool calls never reach the server
- **Rug-pull protection** – tools are pinned; if a server quietly changes a tool, it is quarantined
- **Tool-poisoning protection** – tools with hidden instructions or invisible characters are quarantined

Guide: [MCP Firewall](https://github.com/kayzaa/ZaRemba-AI-Watcher-Official/blob/main/docs/MCP_FIREWALL.md)

### ⚠️ Good to know
- Keep the `zaremba` program in a fixed place – your agents call it from where it was when you ran `guard install`.
- "Experimental" integrations follow the vendors' public docs; please report how they work for you.
- Builds are not code-signed yet; verify with `SHA256SUMS.txt`.
