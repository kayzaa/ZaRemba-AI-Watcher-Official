## 🪤 ZaRemba AI Watcher 0.2.0 – AI Tripwire

Thieves – human, malware or a hijacked AI agent – all go for the same files: wallets, password lists, `.env` files and
API keys. **AI Tripwire** lays out convincing **fake** versions and raises an alarm the moment anything touches them.

### ✨ New
- `zaremba tripwire install` – four decoys: wallet recovery phrase, password list, production `.env`, API keys (all fake, never overwrites your files)
- `zaremba tripwire watch` – live alarm on change, move or delete on every platform; on **Linux also when a decoy is just opened – including which program did it**
- `zaremba tripwire status` – checks the decoys without opening them
- `zaremba tripwire alerts` / `remove` – alarm history, clean removal (changed decoys are kept as evidence)
- `zaremba scan` now reports tripwire alarms (rules `ZRW-TRP-001` … `004`)

Guide: [AI Tripwire](https://github.com/kayzaa/ZaRemba-AI-Watcher-Official/blob/main/docs/TRIPWIRE.md)

### ⚠️ Good to know
- Read-only detection on Windows/macOS comes with the signed desktop app (v1.0).
- Search indexers, backup and antivirus tools may open decoys – see the guide on false alarms.
- Builds are not code-signed yet; verify with `SHA256SUMS.txt`.
