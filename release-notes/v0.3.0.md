## 🌐 ZaRemba AI Watcher 0.3.0 – AI Network Watch

AI-powered malware has to talk to an AI model somewhere – LameHug used Hugging Face, PROMPTFLUX used Gemini.
**AI Network Watch** shows which program on your computer is talking to which AI service, so the ones that shouldn't
stand out.

### ✨ New
- `zaremba net` – programs connected to AI services right now, each with a verdict:
  🚨 high risk · ⚠️ unknown · 🟨 script · ✅ expected · ✅ trusted
- Recognises OpenAI, ChatGPT, Anthropic, Claude, Google Gemini & Vertex AI, Hugging Face, OpenRouter, Mistral, DeepSeek,
  Groq, Together AI, Perplexity, xAI, Cohere, Alibaba Qwen – plus local **Ollama** and **LM Studio** servers
- Flags abused Windows system tools (wscript, mshta, rundll32 …) and programs running from temp or Downloads folders
- `zaremba net watch` – live mode with history (`zaremba net history`)
- `zaremba net allow "name"` – trust the programs you know
- Metadata only – your traffic is never read

Guide: [AI Network Watch](https://github.com/kayzaa/ZaRemba-AI-Watcher-Official/blob/main/docs/NETWORK_WATCH.md)

### ⚠️ Good to know
- `zaremba net` performs DNS lookups of public AI host names to recognise them. `scan` and `tripwire` stay fully offline.
- Very short connections between two checks can be missed; system-event monitoring comes with the desktop app (v1.0).
- Builds are not code-signed yet; verify with `SHA256SUMS.txt`.
