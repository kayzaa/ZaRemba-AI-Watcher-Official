## 🛡️ ZaRemba AI Watcher 0.1.0 – Developer Preview

The first public build of the AI-only security guard: a fast, read-only scanner that shows which AI agents live on your
computer and what could be turned against you.

### ✨ What it finds
- 🧭 **AI Inventory** – Claude Code, Claude Desktop, Cursor, Windsurf, GitHub Copilot, Cline, Roo Code, Continue, Gemini CLI, Codex CLI, Amazon Q, OpenClaw, Ollama, LM Studio
- 🔌 **MCP servers** – known malicious servers (e.g. *postmark-mcp*), silently auto-updating servers, unencrypted remote servers, plain-text keys
- 🧩 **Agent skills** – known malicious skills, skills that download and run code, password-protected "installers"
- ⚙️ **Risky settings** – agents running with no permission prompts or with the sandbox off
- 🔑 **Exposed AI keys** – OpenAI, Anthropic, Google AI, Hugging Face, OpenRouter, GitHub (never printed in full)
- 📦 **Poisoned packages** – e.g. the compromised *Nx* versions from the s1ngularity attack

Verify your download with `SHA256SUMS.txt`. Then run `zaremba scan` – see the [installation guide](https://github.com/kayzaa/ZaRemba-AI-Watcher-Official/blob/main/docs/INSTALL.md).

### ⚠️ Good to know
- Preview builds are **not code-signed yet** – Windows SmartScreen and macOS Gatekeeper will ask once. Signed installers come with v1.0.
- 100 % offline and read-only. No account, no telemetry.
- No security product catches everything – keep your regular antivirus.
