## 🛡️ ZaRemba AI Watcher 1.3.1 – Findings you can act on

Thanks to early feedback: findings were shown, but clicking them did nothing. Now every finding opens a clear
detail window with the right next step.

### ✨ New
- 🖱️ **Click any finding** – see what was found, what to do and where it is, with **Show in folder**.
- 🧊 **Quarantine more** – single files too: AI-steered malware scripts, booby-trapped model files, agent chat histories
  with API keys, and malicious IDE extensions. Always reversible under *Quarantine*.
- ✅ **Mark as reviewed** – checked something (for example an action an agent took in a past session) and it is fine?
  Mark it as reviewed: it leaves the open list and no longer lowers your protection score. One click marks all
  past-session findings at once. *Scan → Reviewed* lists them, **Show again** brings them back.
- ✨ **Explain with AI** right inside the window, if you connected your own AI.
- 🔒 Automatic quarantine now acts only on confirmed threats from the signed threat list – never on heuristic findings.
