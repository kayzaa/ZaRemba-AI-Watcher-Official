## 🛡️ ZaRemba AI Watcher 1.3 – One threat list for every device

Security researchers find new fake AI apps, malicious extensions and poisoned packages every week. Until now only the
desktop app received those updates live. From 1.3 on, **every ZaRemba app** – desktop, command line, browser extension
and Android – downloads the same signed threat list and uses it without waiting for an app update.

### ✨ New
- 🧠 **One signed threat list** – now also with malicious **IDE extensions** (VS Code, Cursor, Windsurf), **browser
  extensions** and **Android apps**, each entry with its public source. Our research team adds newly reported threats
  every day.
- 🧩 **Browser extension 1.3.0** – downloads the list about every 6 hours and checks its signature before using it
  (Chrome 137+ / Firefox 142+; older browsers keep the built-in list). Only the public list is downloaded; nothing is
  sent.
- 🤖 **Android app 1.1.0** – downloads the list when you open the app and with every background check, checks its
  signature, then checks your apps against it. Switch it off in *Settings → Threat list updates*.
- 🖥️ **Desktop & CLI 1.3.0** – malicious IDE extensions now come from the signed list and respect affected versions.

Every app uses the same signature check and the same quality rules – one bad entry and the whole update is rejected,
so a mistake can never flag your legitimate software.

### ⚠️ Good to know
- The installers are not yet signed with Microsoft/Apple certificates – Windows SmartScreen and macOS Gatekeeper ask
  once. See the [installation guide](https://github.com/kayzaa/ZaRemba-AI-Watcher-Official/blob/main/docs/INSTALL.md).
- A threat list only knows threats that were reported. No security product can catch everything.
- Verify downloads with `SHA256SUMS.txt`. The Android app is signed with the ZaRemba release key
  (certificate SHA-256 `FE:D4:BF:3D:77:BB:5E:D5:81:0C:E8:8C:99:20:0C:20:35:3F:D2:F7:BC:7C:48:F5:40:66:94:2A:5D:E6:E1:8B`).
